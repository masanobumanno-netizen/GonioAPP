# v0.5.0 実装・検証状況

## ユーザー決定

複数PCで履歴を共有し、Dropbox APIを使う。mm換算なし、差電圧からdegへ可変2点校正。CONTEC AIO-160802GY-USBを含むAY/GY系4機種。更新はGitHubからWindows Codexでソースを取得し、ローカルビルドする。

## 実装

共有サーバー、実ユーザー認証・権限、共有設定、測定者付き履歴検索、PC内ディスク送信待ち、再送、刺激動画ライブラリ、解析MP4生成、Dropbox OAuth/アップロード、状態表示・再試行、Windowsビルド更新スクリプト。

## 検証内容

- 角度計算、逆向きセンサ、校正不成立、移動平均、CSVのNodeテスト。
- C#取得処理の自己テストと、明示的テストデバイスによる転送・排他・Origin拒否・保存の統合テスト。
- 合成アカウントで初期設定、ログイン、管理者/一般利用者、最終管理者保護、設定、PC内保存、共有履歴、測定者偽装防止、再送、非表示、ログアウトを確認。
- ブラウザの模擬測定で1,181サンプルを記録。共有サーバー停止中にPC内へ保存でき、サーバー復旧後の自動送信を確認。
- Docker内のFFmpegで合成WebMから960×780 H.264 MP4を生成し、動画と角度グラフのフレームを確認。
- Dropboxは模擬HTTPでPKCE、state再利用拒否、refresh token暗号化、アクセストークン再利用、8MiB分割・offset・上書きを検証。実Dropboxへは未接続。

## 再現

READMEのビルド・テストに加え、空のテストサーバーと合成WebMを用意して次を実行する（実データのサーバーで実行しない）。セットアップキーは `local-integration-test-only` に設定する。

```sh
python3 tests/video-integration.py http://127.0.0.1:5281 /path/to/synthetic.webm /tmp/analysis-test.mp4
```
