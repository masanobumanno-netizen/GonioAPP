Gonio Web 0.4.0 / Windows 10・11 x64

【初回導入】
1. ZIPを全て展開します。ZIP内から直接実行しないでください。
2. CONTEC実機を使う場合は公式API-AIO(WDM) x64ドライバをインストールし、Device Utilityで登録・診断します。診断プログラムを閉じます。
3. Install-Gonio.cmdを実行します。.NET/Nodeの追加導入は不要です。
4. 以後はデスクトップの「Gonio Web」から起動します。アプリのコンソールは起動中開いたままにします。
5. ブラウザが開かなければChrome/Edgeで http://127.0.0.1:4173/ を開きます。

【自動更新】
配信先: https://github.com/masanobumanno-netizen/GonioAPP/releases
起動後に公開リリースを確認し、署名とファイルの整合性を確認してダウンロードします。
次回起動時に適用します。計測中に自動再起動することはありません。
更新を適用するときは計測を停止し、アプリのコンソールを閉じてからショートカットで起動してください。
起動確認に失敗すると旧版へ戻し、同じ更新版の再適用を保留します。
オフラインやダウンロード失敗時は現在の版で続行します。更新状態は画面のシステム設定で確認できます。
初回の公開リリースがまだない場合は更新確認エラーになりますが、測定は可能です。
Start-Gonio.cmdは従来のポータブル起動専用で、自動更新しません。
CONTECドライバは自動更新の対象外です。

【実機】
対応: AI-1608AY-USB / AIO-160802AY-USB / AI-1608GY-USB / AIO-160802GY-USB
アナログ入力のみを使用。全機種シングルエンド・±10V、物理チャンネル0〜7、100Hz。
1. 入力元をCONTECへ変更。
2. Device Utilityの登録名（例AIO000）と、Ch1/Ch2に割り当てる異なる物理番号を入力。
3. 「実機に接続」。この時点から校正用の連続取得が開始します。
4. 45°/90°で各1〜5秒平均を取得して毎回校正。電圧差から直接deg換算します。
5. 測定停止後は実機を切断します。次回は再接続・再校正してください。
切断や取得異常時は中断として保存し、模擬値へ切り替えません。
0.3.0のリピート設定不備を修正しました。実機試験には0.4.0以降を使用してください。

【保存先】
アプリ: %LOCALAPPDATA%\GonioWeb\app
生電圧: %LOCALAPPDATA%\GonioWeb\streams
接続中の校正・一時停止・計測を含む全電圧CSV、取得条件JSON、終了理由JSONを保存します。
画面から出力する測定CSVとは収録範囲が異なります。
履歴と表示設定はブラウザ内に保存します。更新後も同じブラウザ・同じURLを使用してください。
更新処理は保存データを削除しません。重要な測定はCSV等で出力してください。

【確認が必要な事項】
Macで自動テストとWindows x64クロスビルドを実施済みです。
Windowsでのインストール・自動更新の切替・CONTEC実機取得は未検証です。
100Hz精度、既知電圧との比較、USB切断後の復帰、カメラ同期精度を実機で確認してください。
サンプルの時刻はホスト開始時刻＋サンプル番号からの推定値で、ハードウェア時刻ではありません。
本番認証、Dropbox共有、解析動画の生成は未実装です。

【困ったとき】
DLLなし: 公式x64ドライバを確認してください。
機器なし: 登録デバイス名・USB接続を確認してください。
ポート使用中: 以前のGonio Webのコンソールを閉じてください。
未対応モデル: 上記4型番のみ対応しています。
更新確認失敗: GitHub公開リリースとネットワークを確認してください。現在の版の利用は継続できます。
